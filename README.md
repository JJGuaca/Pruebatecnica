# Pruebatecnica
Prueba Crud Angular VS Drupal
Para desplegar y/o realizar las pruebas correspondientes, en cualquiera de los dos casos, se siguen las pautas correspondientes

Angular: clonar el proyecto, abrir y ejecutar comando ng -serve
Drupal: clonar el proyecto, (ejecutado mediante ddev), ajsutar los valores de conexion en base de datos ya sea en ddev.settings.php o settings.php
restaurar base de datos
posterior a esto ejecutar composer install
para actualizar dependenciaas
con ayuda de druhs se ejcuta los comandos de "drush config-import" para importar las configuraciones por defecto enviados desde mi pc
